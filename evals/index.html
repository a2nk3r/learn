Mastering AI Evals: From Basics to Hands-On

A self-paced manual for software engineers who test code for a living and now need to test language models. Read the theory here; write and run every evaluation yourself in VS Code and the terminal. Nothing on these pages executes.

How to use this manual

Each Part opens with a mental model that maps its eval practice onto a software-testing habit you already have, then teaches the practice with cited sources. Each Part ends in a lab you build in a local folder called evals-lab/. The pages show code to copy; your terminal runs it.

Pages marked not yet written are planned and will be added in order.
